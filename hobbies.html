My Hobbies

Video Editing

One of my main hobbies is doing video editing. Being a kid who watched a lot of YouTube when I was younger, I always wanted to become one myself and because of that, I decided to teach myself how to use video editors.


MAGIX Vegas Pro

I've been making videos in Vegas Pro since I was 14 years old. It's my program of choice, mainly because the program originally started as a music-creation program, so it has very elaborate audio editing features.

While I do enjoy using the program, it is very notorious for being unstable and crashing often. It was the only program I really tried to use until fairly recently, and while it's been nicer to use more stable programs, I still find myself going back to Vegas because nothing else feels as good to use.

DaVinci Resolve

I've recently been learning to use DaVinci Resolve, as it was required for a film class I took, and it's also available on Linux (my main operating system of choice), unlike Vegas Pro.

Using DaVinci has quite a bit of a learning curve. The main thing that separates it from other video editors is that it has a handful of different menus for editing different parts of videos. It has the main tab, and then separate tabs for doing audio editing, colour grading, making visual effects, and rendering.
